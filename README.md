# HTTP Forge AI 🤖

**MCP server companion for GitHub Copilot, Claude & Cursor.**

Connects your HTTP collections to AI agents via the [HTTP Forge](https://marketplace.visualstudio.com/items?itemName=henry-huang.http-forge) MCP server — auto-starts on launch, generates config for your AI client in one click.

> HTTP Forge is a free Postman / Bruno / Thunder Client alternative for VS Code.

## What you get

✅ MCP server **auto-starts** when VS Code launches  
✅ One-click config generation for **Copilot**, **Cursor**, and **Claude Desktop**  
✅ Dashboard with setup guide on first install  
✅ Works with GitHub Copilot, Claude, Cursor, Continue.dev, and any MCP client

## What your AI can do

Ask in natural language — the AI calls the right MCP tool automatically:

- *"Run the Auth collection and fix any failures"*
- *"Scan this collection for hardcoded tokens"*
- *"Generate edge-case tests for the POST /users endpoint"*
- *"Analyse coverage against my OpenAPI spec"*
- *"Heal the assertions that broke after the API changed"*

60+ tools covering: run, analyse, generate, enhance, heal, manage.
